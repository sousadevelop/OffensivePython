# Cybersecurity Python Labs

Educational Python labs for cybersecurity fundamentals in controlled, authorized environments.

This repository is intended for local study, defensive learning, and explicit lab exercises only. Do not use these scripts against systems, networks, websites, accounts, files, or phone numbers without prior authorization.

## Scope

The repository contains small study labs for hashing, password generation, network programming, local port scanning, web parsing, steganography, and metadata inspection. They are learning exercises, not production security tools.
