# Contributing

## Publication Rules

- Keep changes educational and scoped to authorized laboratory use.
- Do not add real targets, credentials, tokens, payloads, personal data, or scan output.
- Use local or documentation-reserved placeholders.
- Do not add operational instructions that make abuse easier.
- Review screenshots and generated files before committing.

## Pull Request Checklist

- [ ] The change is appropriate for an authorized lab.
- [ ] Examples use placeholders such as `localhost`, `192.0.2.1`, or `https://example.com/`.
- [ ] No credentials, secrets, private paths, or personal data were added.
- [ ] Documentation preserves the ethical scope.
- [ ] Generated artifacts and editor scratch files are excluded.
