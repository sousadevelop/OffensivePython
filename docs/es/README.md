# Cybersecurity Python Labs

## Visión general

Este repositorio contiene pequeños labs educativos en Python sobre fundamentos de ciberseguridad. Úsalos solo en entornos locales, redes aisladas, sistemas propios o escenarios explícitamente autorizados.

Los scripts son ejercicios de aprendizaje, no herramientas aprobadas para operaciones ofensivas reales.

## Alcance ético

- Obtén autorización antes de realizar cualquier prueba.
- Prefiere `localhost`, `127.0.0.1` y redes de laboratorio aisladas.
- Usa valores reservados para documentación como `192.0.2.1`.
- No uses credenciales, teléfonos, URLs, archivos o datos personales reales.
- No publiques resultados de escaneo o información de terceros.

## Áreas de estudio

El repositorio incluye labs locales sobre hashes, generación de contraseñas, permutaciones de texto, sockets, escaneo de puertos, ping, cálculos IP, parsing web, esteganografía y metadatos.

Los labs de red, web y metadatos requieren autorización explícita.

## Instalación

```bash
python -m venv .venv
pip install -r requirements.txt
```

## Placeholders seguros

- `localhost`
- `127.0.0.1`
- `192.0.2.1`
- `https://example.com/`
- `LAB_PLACEHOLDER_MESSAGE`

## Limitaciones

- Algunos scripts son estudios iniciales o incompletos.
- Los labs de red generan tráfico y deben permanecer en entornos autorizados.
- Los servicios externos pueden recopilar metadatos.
- Este repositorio no ofrece instrucciones para actuar contra objetivos reales.

Consulta [SECURITY.md](../../SECURITY.md) y [SECURITY_NOTES.md](../../SECURITY_NOTES.md).
